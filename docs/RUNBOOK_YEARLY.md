# RUNBOOK_YEARLY

연간호를 만드는 절차를 담는다.

## 0. 먼저 읽는다

- [`../AGENTS.md`](../AGENTS.md) 의 **문서 작성 규칙**.
- [`INTENT.md`](INTENT.md) 의 **품질 기준**.
- [`RUNBOOK_QUARTERLY.md`](RUNBOOK_QUARTERLY.md) 전체. 연간호는 분기호의 구조를 그대로 쓴다.

## 분기와 무엇이 다른가

- **입력이 분기호다.** 주간호를 다시 읽지 않는다.
- **아는 범위는 그 해의 분기호까지다.** 그 해 안에서 결말이 나지 않은 사안은 **"그 해가 끝난 시점까지 진행 중"** 으로 쓰고 끝낸다.

## 1. 대상 연도 확정

```bash
Y=${WEEK%%-*}                       # 발행한 주차의 ISO 연도
N=${WEEK##*-W}                      # 발행한 주차 번호
LAST=$(date -d "$Y-12-28" +%V)      # 그 해의 마지막 ISO 주차
```

- `N` 이 `LAST` 일 때만 돈다. 그 해의 Q4 분기호를 발행한 뒤다.
- `content/year/<Y>.md` 가 이미 있으면 덮어쓰지 않고 종료한다.

## 2. 입력

입력은 **그 해의 분기호 네 개뿐**이다. 분기호가 이미 추세를 뽑은 결과이므로, 52주를 다시 읽으면 분기호가 한 일을 되풀이한다.

분기호가 빠진 분기가 있으면 **그 사실을 본문에 밝힌다.**

## 3. 흐름과 단발

구조는 분기호와 같다. 흐름 다섯, 단발 다섯이다. 고르는 방법과 순서, 문체, 도입 문단은 분기 런북 3~6절을 따르되 주차를 분기로 바꿔 읽는다.

- 한 해에 걸친 흐름은 **여러 분기의 흐름이 이어진 것**이다. 한 분기에만 있던 흐름은 연간에서 단발 후보다.
- 근거는 분기호 항목으로 건다. 앵커는 `flow-<번호>` 와 `single-<번호>` 이며, 연간호는 `/year/<Y>/` 에 놓이므로 `../../quarter/<Y>-Q<분기>/#flow-1` 꼴이 된다.

## 4. 콘텐츠 파일 작성

`content/year/<Y>.md` 에 저장한다.

```markdown
---
year: 2026
period_start: 2025-12-29
period_end: 2027-01-03
---

(이 해가 어떤 해였는지 한 단락)

## 흐름

### 1. 제목

- **전개**: …
- **근거**: [2026-Q1 흐름 2](../../quarter/2026-Q1/#flow-2) / [2026-Q3 흐름 1](../../quarter/2026-Q3/#flow-1)

## 단발

- …했다. [2026-Q2 단발 3](../../quarter/2026-Q2/#single-3)
```

- 프론트매터의 `year` 는 파일명과 같아야 한다. 빌드가 검사한다.
- 기간은 그 해 W01 의 월요일부터 마지막 주차의 일요일까지다(KST). ISO 연도라 달력 연도와 며칠 어긋난다.
- 나머지 형식은 분기 런북 7절과 같다.

## 5. 점검과 발행

발행 전 점검은 분기 런북 8절과 같다. 근거 링크가 모두 그 해의 분기호를 가리키는지를 함께 본다.

```bash
npm ci && npm run build
git add content/year/<Y>.md
git commit -m "Publish <Y> annual"
git push origin main
```

**배포된 페이지를 받아 본다.**

```bash
SITE=https://yg-moon.github.io/ai-weekly-news
curl -s "$SITE/year/<Y>/" -o /tmp/pub.html -w '응답: %{http_code}\n'
echo "흐름: $(grep -c '<article class="item"' /tmp/pub.html)건"
echo "단발: $(grep -c '<li id="single-' /tmp/pub.html)건"
echo "목록: $(curl -s "$SITE/<Y>/Q4/" | grep -c "year/<Y>/")건"
```

응답 200, 흐름 5건, 단발 5건, 목록 1건이어야 한다. 목록은 분기 탭 옆의 `연간` 칩이다.

## 아직 검증되지 않은 것

- 이 절차는 한 번도 실행되지 않았다. 첫 실행은 2026-W53 을 발행하는 2027-01-04 다.

빌드는 준비돼 있다. 뼈대 파일로 `/year/<Y>/` 가 나오고 5절의 세 확인 명령이 흐름 5·단발 5·목록 1 을 세는 것까지 로컬 빌드로 확인했다. 실제 주소에서는 첫 연간호를 내는 날 확인한다.
