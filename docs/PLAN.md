## 해보고 알게 된 것

- 권한 설정은 `ask` 가 `allow` 보다 우선한다. 어느 설정 파일에서 오든 그렇다. 저장소 `.claude/settings.json` 에 커밋·푸시를 허용해도 사용자 전역 `ask` 가 있으면 로컬에서는 계속 묻는다.
- 사용량 한도를 비용으로 환산하면 5시간 한도가 약 $27, 7일 한도가 약 $180($175~190)이다. 5시간 한도를 다 쓰면 7일 한도의 약 15%가 든다. 2026-10-03 사실 대조 작업($22.6)이 5시간 85%, 7일 36→49% 를 쓴 것으로 쟀다. 하위 에이전트 출력 토큰이 덜 잡혀 금액은 조금 낮을 수 있고, 두 한도의 비율이 더 믿을 만하다. 2026-10-04 아침 작업($14 안팎)도 5시간 55% 로 같은 비율이었다. (예전 W31 기준 $40·$400 은 표본이 작아 크게 잡혔다.)
- 모델을 바꾸면 비용이 크게 달라진다. W38 은 `claude-opus-5` 로 $15.05 였고, `claude-opus-5-5` 로 돈 백필은 $4~7 이다. 비용의 대부분인 캐시 읽기 단가가 2.5배 차이 난다.
