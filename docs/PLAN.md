## 해보고 알게 된 것

- 물가 항목의 주요 매체 원문을 찾지 못해 `(보조 매체)` 로 표기했다. 주요 매체가 보도했을 사안인데 수집 풀에 잡히지 않는 경우를 어떻게 다룰지 방법이 더 필요하다.
- 네이버 랭킹은 EUC-KR 이고 Node 의 `fetch` 는 403 을 받아 `curl` 로 받는다. OpenAI 뉴스룸(403)과 Wall Street Journal(401)은 원문을 받을 수 없다.
- 실행 환경은 UTC 이며 회수되면 사라진다. 남길 것은 반드시 커밋한다.
- 세션에서 저장소 생성과 Pages 활성화는 불가능하다. 사용자가 직접 처리했다.
