## 해보고 알게 된 것

- 권한 설정은 `ask` 가 `allow` 보다 우선한다. 어느 설정 파일에서 오든 그렇다. 저장소 `.claude/settings.json` 에 커밋·푸시를 허용해도 사용자 전역 `ask` 가 있으면 로컬에서는 계속 묻는다.
- 사용량 한도를 비용으로 환산하면 5시간 한도가 약 $40($38~43), 7일 한도가 약 $400($270~810)이다. W31 로컬 백필 전후 `/usage` 사용률 차이(5시간 8→28%, 7일 70→72%)를 세션 전체 비용으로 나눴다. 7일은 정수 % 오차 때문에 범위가 넓다.
- 모델을 바꾸면 비용이 크게 달라진다. W38 은 `claude-opus-5` 로 $15.05 였고, `claude-opus-5-5` 로 돈 백필은 $4~7 이다. 비용의 대부분인 캐시 읽기 단가가 2.5배 차이 난다.
- 실행 기록의 `session` 은 CLI 세션 ID 이고 대화 기록 파일 이름과 같다. claude.ai 세션 ID(`cse_…`·`session_…`, 커밋의 `Claude-Session:` 링크)와는 다른 값이다. 클라우드도 `CLAUDE_CODE_SESSION_ID`·`CLAUDE_CODE_REMOTE=true` 를 두는 것을 2026-09-27 대화형 세션 두 곳에서 확인했다. 정기 실행의 claude.ai 세션은 루틴 실행 목록에서 시각으로 찾는다.
