# 프로젝트 제작 기록

사람용 기록이다. 날짜는 KST, 비용과 횟수는 `data/build/` 에 있다.

## v1 (2026-09-07 ~ 2026-10-05)

### 뼈대 (09-10 ~ 09-17)

- **09-10** 저장소와 문서 구조를 만들고 GitHub Pages 로 배포했다.
- **09-13** 첫 주간호 2026-W36 을 발행했다.
- **09-14** 검색 대신 매체 목록에서 헤드라인을 모으는 방식으로 바꿨다. DECISIONS 와 QUALITY_CHECKS 를 만들었다.
- **09-17** 정기 실행 루틴으로 주간호를 만드는 시험을 했다(W35).

### 형식과 지난 호 (09-21 ~ 09-28)

- **09-21** 분기호·연간호 형식을 정하고 목록을 탭으로 나눴다.
- **09-26** 발행물마다 비용과 시간을 기록하고 통계 페이지를 열었다. 지난 호 채우기를 시작했다.
- **09-27** 주간호에 목차를 넣고 통계를 기간별로 나눴다.
- **09-28** 지난 호 채우기를 W14 까지 마쳤다. 첫 분기호 2026-Q2·Q3 를 발행하고 분기 루틴을 따로 만들었다. 통계에 인용 매체를 더했다.

### 영문판과 검사 (09-29 ~ 10-03)

- **09-29** 이전·다음 호 이동과 링크 미리보기를 넣었다.
- **09-30** 로고를 넣고, 분기호 항목에 "왜 중요한가"를 더했다.
- **10-01** 출처 링크가 깨지면 배포를 멈추는 검사를 넣었다. 사이트 이름을 AI Weekly News 로 정했다. 영문판을 열고 지난 호를 모두 번역했다.
- **10-03** 본문 수치가 출처에 있는지 보는 검사를 넣었다. 빌드 스크립트를 나누고 테스트를 더했다.

### 공개 준비 (10-04 ~ 10-05)

- **10-04** 지난 호를 모두 사실 대조해 고쳤다. 소개 페이지, 피드백 창, 검색 노출, 방문자 통계를 더했다.
- **10-04** 진행 중 분기호, RSS, 404 페이지, 검색 페이지, 다크 모드를 넣었다.
- **10-05** W40 을 영문판과 함께 발행했다. 화면 간격과 색을 정리하고 화면 점검 스크립트를 만들었다. 발행 시각을 주간 월요일 06:00, 분기 07:00 으로 옮겼다.
