# exp3. 사용량 한도를 비용으로 환산하기

## 목표

Claude 구독의 5시간·7일 사용량 한도가 API 정가로 얼마인지 잰다. 작업 분량("5시간 사용량의 80% 안에서")을 미리 정하고, 정기 발행이 한도에 막히지 않게 하는 데 쓴다.

## 방법

- 작업을 마친 뒤 `usage.mjs` 로 그 창에서 세션과 하위 에이전트가 쓴 비용을 정가로 환산한다.
- 같은 때 사용자가 사용량 화면의 5시간·7일 퍼센트를 읽어 준다.
- 비용 ÷ 퍼센트로 한도를 추정한다. 다른 세션이나 claude.ai 대화가 같은 창에 있으면 비용이 덜 잡혀 한도가 작게 나온다.

## 지금 쓰는 값

- **5시간 한도는 $30 으로 잡는다**(사용자 2026-10-12). 측정은 $25.5~32, 평균 약 $28 로 퍼져 있지만 정가 환산이 추정이라 그 정도 흔들림은 남는다. 80% 는 $24 다. 한도가 그 범위 어디여도 80% 안이면 넘지 않는다. 측정이 쌓이면 $30 근처로 모이는지 본다.
- **7일 한도 ≈ $180~230.** 5시간 한도를 다 쓰면 7일의 약 14~15% 다.
- 하위 에이전트로 백필 한 주(재수집·셈·재검토)는 약 $1, 본문만 보는 제목 검토는 한 주 약 $0.1, 주간 정기 발행 한 번은 $7.5~9 다.
- 정기 발행(월 06:00)과 같은 5시간 창에 큰 작업을 넣지 않는다. 발행이 한도에 막힐 수 있다.
