# AI Weekly News

**한국어** | [English](README.en.md)

### Website: [yg-moon.github.io/ai-weekly-news](https://yg-moon.github.io/ai-weekly-news/)

지난 한 주의 뉴스를 국내·해외·AI 각 5건으로 정리합니다. 주간호가 쌓여 분기·연간 트렌드로 이어지는 것이 목표입니다.

## 발행물

- **주간호**: 매주 월요일 오전 6시(KST)에 발행합니다.
- **분기호**: 주간호를 모아 분기의 흐름을 정리합니다. 분기 도중에는 4주차부터 진행 중인 판을 매주 고쳐 씁니다.
- **연간호**: 분기호를 모아 한 해를 정리합니다.

## 발행 원칙

- **그 주의 헤드라인을 전부 읽습니다.** 주요 언론사와 헤드라인 소스를 통째로 받는 것에서 시작합니다.
- **빈도로 순위를 매깁니다.** 같은 사안이 며칠에 걸쳐 몇 개의 매체에 반복됐는지 세어 얼마나 크게 다뤄졌는지 측정합니다.
- **기사 원문과 대조합니다.** 수치·날짜·인용은 원문을 직접 받아 확인한 것만 씁니다.
- **그 주에 알 수 있었던 것만 씁니다.** 각 주간호는 그 시점의 기록으로 남습니다.

## 제작 방식

- 사람이 설계한 절차에 따라 AI가 수집하고 요약합니다. 각 항목의 출처 링크에서 원문을 확인할 수 있습니다.
- 발행마다 든 비용과 시간, 인용한 매체는 [통계](https://yg-moon.github.io/ai-weekly-news/stats/) 페이지에 공개합니다.

## 저장소 구성

- `content/`: 발행물 원고
- `docs/`: 설계 의도와 발행 절차
- `static/`: 아이콘과 링크 미리보기 이미지
- `scripts/`: 사이트 빌드와 검사
- `data/`: 발행마다 남기는 실행 기록
