# ai-weekly-news

### Website: [yg-moon.github.io/ai-weekly-news](https://yg-moon.github.io/ai-weekly-news/)

지난 한 주의 뉴스를 국내·해외·AI 각 5건으로 정리합니다. 주간호가 쌓여 분기·연간 트렌드로 이어지는 것이 목표입니다.

## 발행 원칙

- **그 주의 헤드라인을 전부 읽습니다.** 주요 언론사와 헤드라인 소스를 통째로 받는 것에서 시작합니다.
- **빈도로 순위를 매깁니다.** 같은 사안이 며칠에 걸쳐 몇 개의 매체에 반복됐는지 세어 얼마나 크게 다뤄졌는지 측정합니다.
- **기사 원문과 대조합니다.** 수치·날짜·인용은 원문을 직접 받아 확인한 것만 씁니다.
- **그 주에 알 수 있었던 것만 씁니다.** 각 주간호는 그 시점의 기록으로 남습니다.

## 유의 사항

- 최신 속보가 아니라 완결된 주간의 정리입니다. 한 주의 범위는 월요일부터 일요일까지입니다.
- 수집과 요약은 AI가 합니다. 사람이 개별 항목을 일일이 검증하지는 않으므로, 각 항목의 출처 링크로 확인해 주세요.
